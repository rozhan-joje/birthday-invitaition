Optional sound files (mp3). Missing files are fine — a soft built-in chime is used instead.

opening.mp3   -> plays on the first screen (after the guest turns sound on)
click.mp3     -> small tap sound
success.mp3   -> success chime (memory found, access granted, YES)
magic.mp3     -> magical transition / opening the envelope
memory-2.mp3  -> example voice message (see MEMORIES in script.js)

Keep each file small (< 200 KB) so the site loads fast on mobile.
