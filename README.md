# Birthday Invitation — دعوت‌نامهٔ تعاملی

یک مینی‌تجربهٔ ۲ تا ۳ دقیقه‌ای با HTML + CSS + Vanilla JS (بدون هیچ فریم‌ورک). هویت بصری از کارت دعوت گرفته شده است.

## نسخهٔ ۲ — جادویی‌تر + Tailwind

- **Tailwind:** رنگ‌ها، فونت‌ها و انیمیشن‌های `bob / flicker / inkin` در `tailwind.config.js` تعریف شده‌اند و بخشی از صحنه‌ها با utility class نوشته شده‌اند. خروجی آماده در `tailwind.css` هست، پس برای Deploy **نیازی به build نیست**. فقط اگر کلاس‌های Tailwind را در `index.html` یا `script.js` عوض کردی: `npm i` سپس `npm run build`.
- **Easter egg (ایدهٔ ۶):** قبل از باز کردن پاکت، سه بار سریع روی مهر بزن. متنش در `EASTER_EGG` است.
- **موسیقی ملایم (ایدهٔ ۷):** بعد از روشن کردن 🔊، یک هارپ آرام و تولیدشده پخش می‌شود. اگر `assets/music/ambient.mp3` بگذاری، به‌جای آن پخش می‌شود. در صحنهٔ آخر جایش را به موسیقی تولد می‌دهد.
- **حال‌وهوای جادویی:** شمع‌های شناور در صحنه‌های اول، جرقه‌های طلایی دنبال انگشت/موس (مثل عصا)، رد پاهای جوهری روی نقشه با هر خاطره، و نماد مهر قابل تغییر با `SEAL_SYMBOL`.

## شروع با موسیقی

مرورگرها بدون لمس کاربر اجازهٔ پخش صدا نمی‌دهند. برای همین اول یک صفحهٔ «مهر» نمایش داده می‌شود؛ لمس مهر، موسیقی را از همان لحظه شروع می‌کند. گزینهٔ «ورود بدون صدا» هم هست. متن‌ها در `TEXT.gateTitle` و `TEXT.gateNote`.

## موزیک واکنش‌گرا

- هر خاطره‌ای که روی نقشه پیدا شود یک نت بالاتر از گام می‌زند؛ با پیدا شدن آخرین نقطه، یک آکورد کامل پخش می‌شود.
- وقتی پیام صوتی یک خاطره پخش شود، موزیک زمینه نرم کم می‌شود و بعد از پایان یا بستن پنجره برمی‌گردد.

## ویرایش متن‌ها: بالای `script.js`

همهٔ چیزهایی که لازم است عوض کنی (نام، رمز، تاریخ، اطلاعات جشن، سؤال‌های هر مرحله، پیام‌های طنز NO و …) در **بخش ۱ بالای `script.js`** است (تا خط «2 — HELPERS»). بقیهٔ فایل منطق برنامه است.

## سه مرحلهٔ نقشه (سؤال‌ها)

| مرحله | سؤال پیش‌فرض | ورودی مهمان |
|---|---|---|
| ۱ | وقتی منو می‌بینی یاد چی می‌افتی؟ یا عکسی از خودمون که دوست داری | **عکس** (+ توضیح اختیاری) |
| ۲ | اولین بار کجا همدیگه رو دیدیم و چجوری بود؟ | **نوشته** |
| ۳ | یه راز بهم بگو 🤫 | **نوشته** |

بعد از این‌ها نقطهٔ چهارم (مقصد/Party) باز می‌شود. برای تغییر: در آرایهٔ `MEMORIES` فیلدهای `title`، `ask`، `placeholder` را ویرایش کن. مقدار `input` می‌تواند `"photo"`، `"text"`، `"voice"` یا `"any"` باشد.

**قانون «حداقل یکی»:** مهمان باید حداقل یک مرحله را جواب بدهد (`UPLOADS.minRequired = 1`). تا آن موقع نقطهٔ مقصد قفل است و پیام «برای ادامه حداقل یک عکس، ویس یا متن برام بفرست» نشان داده می‌شود. اگر بخواهی همه اجباری باشند، عدد را ۳ کن؛ اگر اختیاری، ۰.

## آپلودها و ۲۵ مهمان

جواب‌های هر مهمان در طول مسیر ذخیره می‌شود و در پایان نقشه (با زدن «ادامه») **یک‌جا در یک ارسال** فرستاده می‌شود؛ پس ۲۵ مهمان = ۲۵ ارسال، خیلی کمتر از سقف ۱۰۰ ارسال رایگان Netlify.

**فعال‌سازی (فقط Netlify):**
1. پروژه را روی Netlify Deploy کن (`app.netlify.com/drop`).
   بعد در Netlify → سایتت → **Forms** دکمهٔ **Enable form detection** را بزن و **یک بار دیگر Deploy کن** (پوشه را دوباره بکش و رها کن). تا این کار را نکنی فرم `memories` شناسایی نمی‌شود و ارسال‌ها ذخیره نمی‌شوند.
2. آپلودها را اینجا ببین: Netlify → سایتت → **Forms** → `memories`. هر ارسال شامل نام مهمان، سؤال‌ها، متن‌ها و لینک دانلود عکس‌هاست.
3. ایمیل اطلاع‌رسانی: Forms → Settings & notifications → Form notifications.

**فشرده‌سازی عکس:** عکس قبل از ارسال روی گوشی مهمان کوچک می‌شود (حداکثر ضلع ۲۰۰۰ پیکسل، حجم حدود ۷۰۰KB). اگر عکس از قبل کوچک باشد دست نمی‌خورد. کیفیت فقط به‌اندازه‌ای که لازم است کم می‌شود. یک عکس ۱۰ مگابایتی در تست به ۴۳۲KB رسید. اعداد را در `UPLOADS` عوض کن: `maxImagePx`، `targetImageKB`، `minImageQuality`.

**چطور بفهمم کی چی فرستاده؟**
- اسم مهمان از لینک (`?guest=نام`) می‌آید و در هر ارسال ثبت می‌شود. لینک بدون `guest` باز شود، خود سایت اول اسم را می‌پرسد.
- نام فایل‌ها هم شامل اسم مهمان است، مثلاً `m1-سارا-photo.jpg`.
- اگر دو نفر همنام‌اند، در لینک اسم متفاوت بگذار (مثلاً `?guest=sara-r`).
- برای هر ارسال: Netlify → Forms → `memories` → روی ردیف بزن. می‌توانی همه را با **Export CSV** هم دانلود کنی.

**نکته‌ها:**
- حجم هر ارسال حداکثر حدود ۸ مگابایت؛ عکس‌ها قبل از ارسال کوچک می‌شوند.
- روی کامپیوتر خودت (localhost) ارسال فقط **شبیه‌سازی** می‌شود. تست واقعی فقط بعد از Deploy ممکن است.
- اگر مهمان ارسال نهایی را بی‌اینترنت بزند، پیام خطا می‌بیند و می‌تواند دوباره «ادامه» را بزند.
- برای خاموش کردن کل بخش: `UPLOADS.enabled = false`.

## ساختار

```
birthday-invitation/
├── index.html      ← ساختار صحنه‌ها (معمولاً لازم نیست دست بزنی)
├── style.css       ← رنگ‌ها، فونت‌ها، انیمیشن‌ها
├── script.js       ← بخش ۱ بالای فایل = تمام تنظیمات و متن‌ها؛ بقیه = منطق
└── assets/
    ├── images/     card.jpg (کارت تو) + memory-1..3.jpg (نمونه)
    ├── sounds/     صداهای اختیاری
    └── music/      birthday.mp3 (اختیاری)
```

## چه چیزی را کجا عوض کنم؟ (همه در بالای `script.js`)

| چیز | متغیر |
|---|---|
| نام تولدی | `HOST_NAME` |
| شمارهٔ دعوت‌نامه | `INVITATION_NO` |
| رمز مرحلهٔ Secret Access و سرنخ آن | `SECRET_CODE`، `SECRET_HINT` |
| تاریخ شمارش معکوس | `PARTY_DATE` (فرمت `2026-11-20T20:00:00+03:30`) |
| تاریخ، ساعت، مکان، پوشش، لینک مسیریابی، لینک تأیید حضور | `PARTY_INFO` |
| خاطره‌ها، عکس‌ها، صداها و جای نقطه‌ها روی نقشه | آرایهٔ `MEMORIES` |
| تمام جمله‌ها و پیام‌های طنز NO | `TEXT` |
| مسیر فایل‌های صوتی | `AUDIO_FILES` |

- عکس یا صدای نبود → خطا نمی‌دهد؛ فقط نمایش داده نمی‌شود.
- نقطهٔ `party` تا پیدا شدن بقیه قفل است.
- برای تست سریع یک صحنه: `index.html?scene=map` (نام‌ها: opening, question, letter, secret, map, countdown, info).

## فایل‌هایی که باید خودت بگذاری

| فایل | کجا | توضیح |
|---|---|---|
| عکس‌های خاطره | `assets/images/memory-1.jpg` … | جایگزین نمونه‌ها؛ نسبت ۴:۳، حدود ۸۰۰×۶۰۰، زیر ۱۵۰KB |
| موسیقی تولد | `assets/music/birthday.mp3` | فقط در صحنهٔ آخر و بعد از روشن کردن 🔊 پخش می‌شود |
| صداها | `assets/sounds/opening.mp3, click.mp3, success.mp3, magic.mp3` | اختیاری؛ اگر نباشند صدای زنگولهٔ ملایم داخلی پخش می‌شود |
| پیام صوتی | مسیرش را در `sound` همان خاطره بنویس | مثلاً `assets/sounds/memory-2.mp3` |

هیچ صدایی خودکار پخش نمی‌شود؛ مهمان باید دکمهٔ 🔇/🔊 بالای صفحه را بزند.

## اجرای لوکال

فایل‌ها را با دوبار کلیک روی `index.html` هم می‌توان دید، اما بهتر است با سرور ساده اجرا شود:

```bash
cd birthday-invitation
python3 -m http.server 8000
# بعد در مرورگر: http://localhost:8000/?guest=amir
```

برای تست روی گوشی (همان وای‌فای): آدرس IP کامپیوتر را بزن، مثلاً `http://192.168.1.20:8000`.

## Deploy

**Netlify (ساده‌ترین):** به `app.netlify.com/drop` برو و کل پوشهٔ `birthday-invitation` را بکش و رها کن. لینک آماده است.

**Vercel:**
```bash
npm i -g vercel
cd birthday-invitation
vercel --prod
```

بعد از Deploy، در `index.html` مقدار `og:image` را به آدرس **کامل** تغییر بده تا در تلگرام/واتساپ پیش‌نمایش کارت نمایش داده شود:
```html
<meta property="og:image" content="https://YOUR-SITE.netlify.app/assets/images/card.jpg">
```

## لینک شخصی برای هر مهمان

فقط `?guest=نام` را به آخر لینک اضافه کن:

```
https://YOUR-SITE.netlify.app/?guest=amir
https://YOUR-SITE.netlify.app/?guest=سارا
https://YOUR-SITE.netlify.app/?guest=Ali%20Reza     ← فاصله = %20
```

اگر `guest` نباشد، متن عمومی نمایش داده می‌شود. نام فقط به‌صورت متن ساده نمایش داده می‌شود (امن).

## Performance / Accessibility

- فقط یک تصویر اصلی (کارت) + عکس‌های خاطره که هنگام باز شدن لود می‌شوند (lazy).
- انیمیشن‌ها فقط با `transform` و `opacity`؛ کانواس ذرات حداکثر ۱۵۰ ذره، و روی `prefers-reduced-motion` کم‌تر و ساده‌تر می‌شود.
- فونت‌ها از Google Fonts (Amiri، Cormorant Garamond، Vazirmatn) لود می‌شوند؛ اگر آفلاین باشد، فونت‌های سیستم جایگزین می‌شوند.
- اسکرول افقی وجود ندارد؛ دکمه‌ها حداقل ۴۴px هستند.

## ایده برای نسخهٔ بعد

1. **RSVP واقعی:** ذخیرهٔ پاسخ مهمان‌ها در Google Form یا Supabase و نمایش تعداد مهمان‌ها برای خودت.
2. **رمز متفاوت برای هر مهمان** (مثلاً اسم گربه‌اش!) با `?guest=` و یک جدول رمزها.
3. **ویدیوی کوتاه** به‌جای عکس در بعضی خاطره‌ها.
4. **دکمهٔ «افزودن به تقویم»** (فایل `.ics`) در صحنهٔ اطلاعات.
5. **نقشهٔ تصویری واقعی:** یک نقاشی به سبک همان کارت به‌جای نقشهٔ SVG، با همان مختصات نقطه‌ها.
6. **Easter egg:** ۳ بار لمس روی مهر پاکت، پیام مخفی.
7. **موسیقی ملایم** (کلاویه/هارپ) در پس‌زمینهٔ صحنه‌های میانی.
